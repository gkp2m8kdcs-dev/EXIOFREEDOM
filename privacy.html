1 我们收集的信息

Information We Collect

EXIOFREEDOM 采用"本地优先"架构，绝大多数数据由您直接输入并仅存储于您的个人设备上。 我们仅收集极少量运行所必需的信息，且不涉及可识别个人身份的财务内容上传。

◈ 仅存储于本地
您输入的净资产、收支流水、资产配置、目标金额、交易记录、情景参数等所有财务内容均保存在设备本地 UserDefaults 沙盒中。
◈ 不上传云端
除非您主动通过 iOS 系统分享功能导出 CSV / JSON 文件，否则我们的服务器不会接收、存储或处理任何上述财务数据。
◈ 应用使用统计（可选）
若您同意，Apple 可能会向开发者提供匿名崩溃报告与统计数据，用于改善产品稳定性。此部分由 iOS 系统级控制。
◈ 本地通知
目标里程碑提醒、Action 到期提醒等通知注册于本地 UNUserNotificationCenter，不经过外部服务器中转。

2 信息的使用方式

How We Use Information

我们仅在以下场景使用信息，且所有计算均在本地完成：

  • 运行财务健康分（Health Score）算法，计算储蓄率、债务杠杆、应急储备等七维度评分；
  • 执行情景模拟（Scenario Simulator）的复利、通胀校正与 Months-to-Freedom 计算；
  • 根据目标（Goal）截止日期和金额，自动生成月度投入建议并触发本地通知；
  • 驱动 Application Badge、Widget 等系统级 UI 组件显示您最新的财务概览；
  • 通过 NotificationCenter 在 TabBar 五个页面间同步数据变更刷新，不涉及跨设备传输。

✓ 原则承诺：我们不会将您的财务数据用于广告投放、用户画像构建、信用评估或出售给任何第三方机构。

3 数据存储与安全

Data Storage & Security

我们采用 iOS 平台提供的多种安全机制，多层次保护您的数据安全：

  • 沙盒隔离： 应用数据存储于独立沙盒目录，其他应用在未授权情况下无法读取；
  • File Protection： 支持 Data Protection API，根据设备锁屏状态自动加密持久化文件；
  • 敏感字段哈希： 对于内部标识类字段，使用 FNV-1a 非可逆哈希算法处理，避免明文比对；
  • 数学安全防护： 所有涉及复利、对数的计算（如 monthsToFreedom）均通过 guard isFinite 判断，防止 NaN 崩溃或异常状态泄露；
  • 可控导出： CSV / JSON 导出通过系统分享面板（UIActivityViewController），由您主动选择目标接收方。

4 生物识别信息

Biometric Information

EXIOFREEDOM 提供可选的 Face ID / Touch ID 生物识别安全锁功能（BiometricService）：

  • 生物识别身份验证完全由 iOS 系统 LocalAuthentication 框架执行；
  • 我们从不读取、存储或上传您的指纹、面容或任何生物特征模板；
  • 应用仅接收系统返回的验证成功 / 失败布尔值，用于决定是否解锁主界面；
  • 您可随时在 App「设置 → 安全与隐私」中关闭生物识别锁，改用无密码直入模式。

⚠️ 请注意：若您的设备启用了多生物特征（如多个指纹或面容），所有已注册的生物特征均可解锁 EXIOFREEDOM。若需更严格的访问控制，请在 iOS「设置 → 面容 ID 与密码」中管理。

5 第三方服务

Third-Party Services

当前版本的 EXIOFREEDOM 未嵌入任何第三方分析 SDK、广告 SDK 或社交登录 SDK。应用运行所依赖的系统级框架包括：

  • UIKit / Foundation：iOS 系统基础框架；
  • UserNotifications：本地通知调度；
  • LocalAuthentication：生物识别验证；
  • CoreGraphics / CoreAnimation：图表与动画渲染（均为离线计算）。

若未来版本引入新的第三方服务，我们将在本政策中显著更新并在应用内首次弹窗征得您的明示同意。

6 您的数据权利

Your Data Rights

遵循 GDPR、CCPA 以及其他适用的数据保护法规，您对自己的数据享有以下权利，且 EXIOFREEDOM 从架构层面赋予您直接执行的能力：

  • 访问权： 在「设置 → 财务档案」中可直接查看当前所有财务档案数值；
  • 修改权： 上述数值均可通过点击单元格进入编辑态实时修改，并通过 NotificationCenter 全局同步；
  • 导出权： 在「设置 → Data → Export Data」一键导出全量 CSV 与 JSON 文件；
  • 删除权： 在「设置 → Data → Reset All Data」可一键清空应用内所有用户数据（操作不可撤销，请谨慎）。

如您对行使数据权利有疑问或需要人工协助，请通过第 9 节的方式联系我们，我们将在 15 个工作日内响应。

7 儿童隐私

Children's Privacy

EXIOFREEDOM 是为具有独立财务决策能力的成年用户设计的理财工具，不面向 13 周岁（或您所在司法辖区规定的更高年龄）以下的儿童。 我们不会主动收集儿童的任何个人信息。若您作为监护人发现儿童未经许可使用本应用，可随时通过第 6 节所述方式清除数据，并联系我们。

8 政策变更

Changes to This Policy

当法律要求变更或产品功能发生影响数据处理方式的重大调整时，我们会更新本隐私政策。任何变更将：

  • 在本页面标注新的"最后更新"与"生效日期"；
  • 通过应用内启动弹窗或系统通知方式提示您重新阅读；
  • 对于扩大使用范围的变更，先取得您的明示同意后才会生效。

我们建议您定期查阅本页面以获取最新版本。继续使用 EXIOFREEDOM 即视为您接受更新后的政策内容。
