快速开始 5 分钟配置

1

填写财务档案（Financial Profile）

打开 App 后，进入底部第 5 个 Tab「Settings」，滑动到「Financial Profile」部分，依次填写 Current Net Worth、Annual Income、Monthly Expenses、Total Debt、Expected Return、Inflation Rate 等核心字段。点击任意行即可进入编辑态，输入后全局自动同步。

💡 所有数值仅保存在设备本地，不会上传云端
2

配置资产分类（Asset Allocation）

在 Dashboard 或 Settings 中找到「Asset Allocation」模块，点击右上角 + 新增你的资产类别（如股票、债券、现金、房产、加密货币等），并填入对应金额与备注。配置完成后健康分引擎会自动纳入投资多元化维度评分。

3

设定你的 FIRE 目标

进入「Goals」Tab，点击 + 创建你的第一个里程碑目标——通常建议先设定「Emergency Fund（6 个月支出）」、然后是「25× 年度支出 FIRE Number」。系统会根据截止日期反推每月建议投入，并在临近节点时发送本地通知提醒。

💡 目标进度基于剩余时间线性贡献算法，新建目标不会虚高
4

在 Scenario Simulator 推演未来

进入「Analysis」Tab，在 Scenario Simulator 中拖动 6 个参数滑块，观察「Months to Freedom」「FIRE Year」等关键指标的实时变化。建议先尝试提高储蓄率与投资收益率，这两者对缩短自由时间影响最大。

5

开启生物识别与记录首笔流水

最后前往「Settings → Security & Privacy」开启 Face ID / Touch ID 安全锁；然后在 Transactions Tab 点击 + 记录今天的第一笔收入或支出。完成以上 5 步后，Dashboard 上的财务健康分将首次给出完整评估，后续的每一次提升都有迹可循。

💡 别忘了在 Insight Tab 查看 Health Score 的 7 维度分项诊断

常见问题 FAQ TOP 热门

EXIOFREEDOM 会把我的财务数据上传到云端吗？

+

不会。默认情况下，您输入的所有财务数据（净资产、流水、目标、资产配置、健康分参数等）均存储在 iOS 系统分配给 EXIOFREEDOM 的本地沙盒中，通过 UserDefaults 加密持久化。我们不提供也不强制使用任何云端账户系统。

如需备份或迁移，请使用「Settings → Data → Export Data」功能，导出的 CSV / JSON 文件可通过 AirDrop、iCloud Drive 等您信任的渠道自行保管。

财务健康分（Health Score）是如何计算的？

+

健康分基于 7 个维度加权得出（0–100 分），各维度满分占比与算法要点如下：

  • 储蓄率（20%）：（月收入−月支出）/月收入，≥30% 为满分区间
  • 应急储备（20%）：流动现金 ÷ 月支出，≥6 个月为满分
  • 债务杠杆（15%）：总债务 ÷ 净资产，越低越好
  • 投资配置（15%）：资产多元化程度与风险资产占比
  • 收入多元度（10%）：是否配置被动收入来源
  • 保险覆盖（10%）：基础保险完善度（自定义勾选）
  • 目标进度（10%）：按 Goal 模块完成度综合评估

此外，完成 Insight → Action 卡片中的任务会获得额外加成（最高 +60 分），加成来源会在 UI 上明确展示。

Months to Freedom 出现异常或 NaN 怎么办？

+

该算法在实现上已通过 guard value > 0, value.isFinite 做了数学安全保护，正常使用不会出现 NaN。如仍遇到显示异常，请按以下顺序排查：

  • 确认「Expected Annual Return」大于 0 且小于 100（即不超过 100% 年化）
  • 确认「Monthly Savings」为正数，且「Annual Expenses × 25」> 当前净资产
  • 前往「Settings → Data → Reset All Data」前先导出备份，再重新填入参数
  • 如仍未解决，请导出 CSV 并通过 support@exiofreedom.app 发送给我们

如何开启 Face ID / Touch ID 锁？为什么我找不到入口？

+

请先在 iOS 系统级「设置 → 面容 ID 与密码」（或触控 ID）中至少注册 1 组生物特征。然后在 EXIOFREEDOM 中：

  • 进入底部 Tab 「Settings」
  • 找到分组 「Security & Privacy」
  • 打开 「Biometric Lock」开关即可

开启后，App 每次从后台进入前台或冷启动时都会触发系统级生物验证，验证通过前内容被锁屏遮挡。

小提示：如果该开关置灰不可点，请检查系统「设置 → EXIOFREEDOM → 面容 ID」是否已授权。

换了新手机，如何迁移我的数据？

+

推荐以下 2 种方式迁移：

  • 方式 A（推荐）：在旧设备「Settings → Data → Export Data → JSON」导出全量文件，通过 AirDrop 发送到新设备，在新设备安装后用系统分享面板「用 EXIOFREEDOM 打开」即可导入。
  • 方式 B：将旧手机通过 iTunes / Finder 做完整本地备份后恢复到新手机，UserDefaults 沙盒中的全部数据会被完整迁移。

请注意：CSV 文件仅包含流水与资产明细，不含主题偏好、Action 勾选等元数据，跨设备迁移建议优先使用 JSON 格式。

本地通知（里程碑提醒）不触发怎么办？

+

请依次检查：

  • 系统 「设置 → EXIOFREEDOM → 通知」 是否已允许通知，且「标记」「声音」「横幅」任一开启
  • 在 App 中「Settings → Notifications」确认 「Goal Milestone」 与 「Action Reminder」 开关已打开
  • 目标（Goal）需设置了未来的 Due Date，否则不会注册通知
  • 请勿在设置中关闭该 App 的「后台刷新」权限

如仍异常，请长按 App 图标 → 「编辑主屏幕」→ 删除 App 后重装（务必先导出数据备份！）。

情景模拟（Scenario Simulator）的 Base 值与 Current 值含义？

+

在 Analysis Tab → Scenario Simulator 中，每个参数都有两行数值：

  • Base 值（灰色）：来自您在 Financial Profile 中填写的基线值，代表「不做任何调整」的现状，不可在该页面直接修改。
  • Current 值（金色高亮）：由滑块实时调整的模拟值，代表「假设我把参数改成这个值」。

顶部的「预计 FIRE 年份」「自由倒计时」等结果始终基于 Current 值实时计算。若滑块全部归中，则 Current = Base，结果应与 Dashboard 基线一致。

可以和家人共用一份财务档案吗？

+

EXIOFREEDOM 当前为单机单用户设计，未内建多账户或家庭共享模块。如果您希望与家人共同管理：

  • 可以在同一台 iOS 设备上共用一个账户（需共用 Face ID / 设备密码）
  • 或通过定期导出 JSON 文件、再导入另一台设备的方式手动同步

正式的家庭版（iCloud 多端同步 + 权限分级）已在我们的路线图中，预计 v2.5 版本提供。

进阶使用指南

A

用 Action 系统提升健康分

Insight Tab 中列出的 Action 卡片（如「建立 6 个月应急储备」「配置重疾险」「优化投资组合分散度」等）不仅是建议，勾选完成后还会直接为 Health Score 提供加分。每一项 Action 的难度等级决定了它的加分权重：Easy +5 / Medium +10 / Hard +15 / Expert +30。勾选状态通过 UserDefaults 持久化，可随时取消勾选回溯。

B

CSV vs JSON 导出格式差异

CSV 适合导入 Excel / Numbers 做二次报表分析，文件包含 Transactions（流水）与 Assets（资产配置）两个逻辑 Sheet，但不含 App 偏好设置、Action 勾选状态、Goal 详细结构。JSON 则是完整的状态快照，包含 UserDefaults 中的全部键值，适合备份 / 跨设备迁移 / 程序化二次开发。

💡 建议定期每月导出一次 JSON 作为冷备份
C

浅色 / 深色模式切换

前往 「Settings → Appearance」 可在「跟随系统 / 浅色 / 深色」间切换。主题偏好立即生效并通过 NotificationCenter 跨 Tab 实时刷新，同时持久化到 UserDefaults。Dashboard 的环形进度条、折线图颜色、卡片高亮色都已做了完整的主题适配。
